# 💌 Kisah Kita — 10 Babak Perjalanan Hangat

> A 10-scene interactive memory journey with polaroids, an emotional first-aid kit, and a grand finale.

## About

`kisah-kita` is a warm, nostalgic interactive experience divided into 10 scenes. Each scene is a mini-interaction that revisits shared memories — from knocking on a door, to catching stars, to browsing a polaroid album, to an emotional "P3K" (first-aid kit) for the heart. Ends with a grand finale canvas celebration.

## 10 Scenes

1. 🚪 **Ketuk Pintu** — Knock to begin
2. 🪪 **Verifikasi Identitas** — Identity check
3. ⭐ **Tangkap 7 Bintang** — Catch 7 stars (canvas)
4. 🩹 **Kotak P3K Emosional** — Emotional first-aid kit
5. 🎵 **Our Soundtrack** — Music moment
6. 📸 **Album Polaroid** — Photo album browsing
7. 🤗 **Pelukan Digital** — Digital hug
8. 💌 **Surat dari Hati** — Letter from the heart
9. ❓ **1 Pertanyaan Penting** — One important question
10. 🎆 **Grand Finale** — Canvas celebration

## Features

- Scene-based navigation with progress dots
- Ambient particle canvas
- Music pill toggle
- Toast notifications
- Micro-interactions per scene
- Polaroid album with photo reveals
- Grand finale canvas (confetti/fireworks)

## Tech Stack

- Vanilla HTML / CSS / JS
- Canvas (particles, mini-games, finale)
- Web Audio API (music + SFX)
- Local assets: `angelbaby.mp3` + 12 GIF/PNG stickers

## How to Run

```bash
cd kisah-kita
npx serve .
```
